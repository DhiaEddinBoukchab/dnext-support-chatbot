================================================================================
                            QUICK SETUP
================================================================================

After copying:

1. Install dependencies
   $ cd backend/mcp
   $ pip install -r requirements.txt

2. Make sure backend is running
   $ # Terminal 1
   $ cd backend
   $ python main.py

3. Start MCP server
   $ # Terminal 2
   $ cd backend/mcp
   $ python server_simple.py

4. Test it works
   $ curl http://localhost:8001/health

5. Start using!
   - Python: Use examples/client_simple_python.py
   - cURL:   Run bash examples/curl_examples.sh
   - JS:     See SIMPLE_START.md for examples
